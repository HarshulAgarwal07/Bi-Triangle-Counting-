# Chat Summary — Signed Bi-Triangle Counting Project

## Project goal
Implementing a C++ pipeline for counting **balanced/unbalanced bi-triangles** in **signed bipartite graphs**, building toward an OpenMP-parallelized RSWJ-Count. Based on two papers (both uploaded earlier in this chat):
- **Yang et al., VLDB 2021** — "Efficient Bi-triangle Counting for Large Bipartite Networks" (unsigned WJ-Count → SWJ-Count → RSWJ-Count).
- **Mekala et al. 2026** — "Multi-core & GPU-based Balanced Butterfly Counting in Signed Bipartite Graphs" (BB2K bucketing, M-BBC multi-core pattern).

Planned sequence (per standing memory): Phase A (core+rank) → unsigned RSWJ-Count → signed RSWJ-Count → OpenMP. **Actual path taken diverged slightly**: went SWJ-Count (signed, validated) → Phase A (core+rank, validated) → RSWJ-Count derived **directly in signed form** (skipped a separate unsigned-only RSWJ stage) → validated → now mid-way through OpenMP.

## Core mathematical results (all proven, all empirically validated)

**Central lemma** (generalizes BB2K's Lemma 1): if a cycle is formed by joining two edge-disjoint paths sharing both endpoints, the cycle is balanced (even # negative edges) iff the two paths have matching weight (XOR of edge signs). This applies unchanged to 2-edge wedges (butterflies) and 3-edge super-wedges (bi-triangles) — the proof doesn't depend on path length.

**SWJ-Count (signed)**: bi-triangle = join of two super-wedges; 3 representations per bi-triangle → divide by 3 at the end. Two acyclic correction types (Type-L, Type-U), each computed via a separate pass (over L, then over U). Both corrections' balanced/unbalanced split reduces to comparing wedge parity, because the shared "extension edge" cancels under XOR self-cancellation — proven and implemented.

**RSWJ-Count (signed)**: single unified pass over `V = U∪L`, each vertex explores only rank-higher neighbors (Ψ) anchored at its own rank (σ(v)); **unique** representation per bi-triangle (Theorem 3) → **no divide-by-3**. Four acyclic correction lemmas, all derived and implemented:
- **Type-1.1** (Lemma 2): `Bal += (C(Se,2)+C(So,2))×φ(σ(v),v)`, `Unb += (Se×So)×φ(σ(v),v)`
- **Type-1.2** (Lemma 3, highest-risk piece — needed a second parity-split accumulator `T_even/T_odd` weighted by `φ(σ(v),x)`): `Bal += Te×(Se-1) + To×(So-1)`, `Unb += Te×So + To×Se`
- **Type-1.3+Type-2** (Lemma 4, combined): `Bal += (C(Se,2)+C(So,2))×(d(y)-2)`, `Unb += (Se×So)×(d(y)-2)` — same shape as Type-1.1, different multiplier
- **Self-intersection fix**: same pattern as SWJ — reduces to constant `sign(v,z)`, subtracted `ψ(σ(v),z)` times.
- **Known assumption flagged**: paper's Algorithm 3 line 11 ("Ψ(φ(v),y)") is almost certainly a typo for **Ψ(σ(v),y)** — implemented on that assumption, and it has since passed validation.
